# Money Tracker

Личный трекер расходов в тенге. Это PWA для iPhone: без сервера, работает офлайн, данные хранятся на телефоне.

## Загрузка на GitHub Pages

1. Создай на github.com новый **публичный** репозиторий, например `money`.
2. Загрузи в него **содержимое** этой папки (не саму папку): `index.html`, `app.js`, `styles.css`, `icons.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
   Через терминал:
   ```bash
   cd money-tracker
   git init && git add . && git commit -m "Money tracker"
   git branch -M main
   git remote add origin https://github.com/<твой-ник>/money.git
   git push -u origin main
   ```
3. В репозитории открой **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<твой-ник>.github.io/money/`.

## Установка на iPhone

1. Открой ссылку в **Safari**.
2. Нажми **Поделиться → На экран «Домой»**.
3. Запускай с иконки: приложение откроется на весь экран, без адресной строки.

## Важно про данные

- Данные лежат только в этом приложении на телефоне. В Safari они хранятся отдельно, поэтому вноси записи с иконки на экране «Домой».
- Если удалить иконку, все данные пропадут. Периодически делай **Settings → Export backup** и сохраняй файл в «Файлы» или iCloud Drive. Восстановить его можно через **Import backup**.
- В репозиторий попадает только код, твои данные туда не попадают.

## Обновления

После изменения файлов сделай `git push`. Приложение подтянет новую версию при следующем запуске с интернетом (возможно, его придётся открыть дважды).

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Apple Pay → «Деньги» (через Supabase)

После каждой оплаты Apple Pay автоматизация в «Командах» кладёт сумму, магазин и карту в таблицу Supabase. При открытии «Деньги» забирают покупки, показывают их на проверку (категории подставляются по прошлым покупкам) и удаляют из Supabase. Вся история остаётся только на телефоне.

**Supabase (один раз)**
1. supabase.com → New project (регион, например, Frankfurt).
2. В приложении: Настройки → Apple Pay → «Скопировать SQL». В Supabase: SQL Editor → вставить → Run.
3. Project Settings → API: скопировать **Project URL** и ключ **anon public** → вставить в настройках Apple Pay → «Сохранить и проверить».

**Команда на iPhone** (с очередью: без интернета покупка не теряется, а уходит со следующей)
1. Команды → Автоматизация → «+» → **Транзакция** → выбрать карты → **Запускать сразу**, уведомление выключить → Новая пустая автоматизация.
2. **«Словарь»** с полями (все — Текст): `amount` = Сумма, `merchant` = Продавец, `card` = Карта, `paid_at` = Текущая дата (нажать на переменную → Формат даты: **ISO 8601**).
3. **«Добавить в текстовый файл»**: Словарь → файл `Shortcuts/mamoney-queue.txt`, «Новая строка» включена.
4. **«Получить файл»** `Shortcuts/mamoney-queue.txt` из папки Команды (iCloud Drive), «Ошибка, если не найден» выключить.
5. **«Получить содержимое URL»**:
   - URL — кнопка «URL» в настройках Apple Pay (`…/rest/v1/rpc/inbox_push`);
   - Метод — **POST**;
   - Заголовки: `apikey` = ключ, `Authorization` = `Bearer ` + ключ, `Content-Type` = `application/json`;
   - Тело запроса — **JSON**: `p_secret` = секрет из настроек, `p_lines` = Файл (из шага 4).
6. **«Удалить файлы»**: Файл из шага 4, «Подтверждать удаление» выключить.

Если интернета нет, шаг 5 падает, команда останавливается, а файл с покупкой остаётся — следующая оплата отправит все накопленные. Дата покупки берётся из `paid_at`, поэтому отложенная покупка встанет в свой день. Повторно отправленные копии приложение пропускает.

Обновление со старой команды (POST в `…/rest/v1/applepay_inbox`): ещё раз выполнить SQL из настроек (он безопасен для повторного запуска) и пересобрать команду по шагам выше. Старая команда продолжит работать, просто без очереди.

Ограничения: работает только для оплат картой из Wallet (не Kaspi QR); бесплатный проект Supabase засыпает после 7 дней без запросов.

# Money Tracker

Личный трекер расходов в тенге. Это PWA для iPhone: без сервера, работает офлайн, данные хранятся на телефоне.

## Загрузка на GitHub Pages

1. Создай на github.com новый **публичный** репозиторий, например `money`.
2. Загрузи в него **содержимое** этой папки (не саму папку): `index.html`, `app.js`, `styles.css`, `icons.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
   Через терминал:
   ```bash
   cd money-tracker
   git init && git add . && git commit -m "Money tracker"
   git branch -M main
   git remote add origin https://github.com/<твой-ник>/money.git
   git push -u origin main
   ```
3. В репозитории открой **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<твой-ник>.github.io/money/`.

## Установка на iPhone

1. Открой ссылку в **Safari**.
2. Нажми **Поделиться → На экран «Домой»**.
3. Запускай с иконки: приложение откроется на весь экран, без адресной строки.

## Важно про данные

- Данные лежат только в этом приложении на телефоне. В Safari они хранятся отдельно, поэтому вноси записи с иконки на экране «Домой».
- Если удалить иконку, все данные пропадут. Периодически делай **Settings → Export backup** и сохраняй файл в «Файлы» или iCloud Drive. Восстановить его можно через **Import backup**.
- В репозиторий попадает только код, твои данные туда не попадают.

## Обновления

После изменения файлов сделай `git push`. Приложение подтянет новую версию при следующем запуске с интернетом (возможно, его придётся открыть дважды).

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
